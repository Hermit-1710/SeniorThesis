# ST4001 Senior Thesis 毕业论文要求清单

依据 `Syllabus_of_ST_4001_AY_25-26.pdf` 整理，适用于 AY 2025-2026。

## 关键时间节点

| 时间 | 事项 |
| --- | --- |
| 2025-10-24 前 | 在 PeopleSoft 中选择并排序 3 个 thesis projects。 |
| 项目分配后 1 周内 | 与导师/共同导师开题会，填写 Task Plan。 |
| 2026-01-23 前 | 提交 thesis proposal PDF 到 Blackboard；按时提交得 10 分。 |
| 2026-03-27 前 | 提交 Midterm Self-check Form；按时提交并有导师签名得 5 分。 |
| 2026-05-22 前 | 提交 thesis draft PDF 到 Blackboard，并附带导师评论和签名的 Assessment Form。 |
| 2026-06-03 前 | 若委员会不同意答辩，委员会主席需向 UA office 提交 Assessment Form。 |
| 2026-06-04 | Oral defense。 |
| 2026-06-12 前 | 提交双面打印装订版 thesis book 到 UA office；同时提交最终电子版 PDF 到 Blackboard。 |

## Thesis Proposal 要求

Proposal 需在导师指导下按 Appendix IV 模板撰写，并经导师批准签名后提交为一个 PDF 文件。内容应包括：

1. 充分的文献综述，或行业/市场调研，说明领域前沿、障碍、项目创新性与意义。
2. 项目目标，以及实现目标的研究方法或设计方案，并给出充分论证与验证思路。
3. 时间计划与预期成果。
4. 初步结果或当前进展。
5. 至少 10 篇参考文献，其中网站引用不超过 3 篇，中文文献不超过 3 篇。

## 最终毕业论文内容要求

每位学生需在导师指导下独立完成 senior thesis。正文主体内容不含参考文献，至少 20 页，并使用 ZJUI 模板 Appendix VI。论文应包括但不限于：

1. 标题、摘要，以及论文结构概述。
2. 文献综述和项目介绍章节。
3. 研究工作章节，例如实验、编程、设计图、测试、理论推导等。
4. 结果分析章节，例如实验结果、软件与测试结果、设计产品与测试结果等。
5. 至少 10 篇参考文献；中文文献不超过 3 篇，网站引用不超过 3 篇。
6. 结论。

不同项目类型的补充要求：

| 类型 | 应包含内容 |
| --- | --- |
| Research project | 充分文献综述、实质性研究实验、详细数据分析、充分参考文献、项目结论。 |
| Engineering design project | 充分文献综述、详细设计图、设计产品展示照片/视频、测试方法、测试结果与分析、项目结论。 |
| Software developing project | 充分文献综述、software vendor list、软件说明和使用手册、软件测试分析报告、项目结论。 |

## 格式与装订顺序

正式纸质版 thesis book 的装订顺序：

1. Cover page
2. Content checklist
3. Academic Integrity Commitment
4. Acknowledgements
5. Abstract
6. Content table，包括页码
7. Written thesis，正文页码从 1 开始
8. References
9. Appendix，如 publication acceptance letter、publication full text、patent letter 等
10. Author CV
11. Task Plan
12. Assessment Form of Senior Thesis
13. Defense Minutes

打印要求：

- Content table、written thesis、references、appendix 需要双面打印。
- 其余部分单面打印。
- 最终纸质版应双面 A4 打印并装订。
- 电子版 final thesis book 上传为单个 PDF；电子版不要求包含 checklist、commitment、task、assessment forms、defense minutes 等过程记录文件。

## 诚信承诺与查重

学生需签署 Academic Integrity Commitment，并遵守学术诚信和知识产权要求。ZJUI 会组织论文查重，查重范围包括 abstract、main content 和 references。

查重处理规则：

| 查重率 | 处理 |
| --- | --- |
| < 10% | 通过，按查重报告适当修改。 |
| 10%-20% | 修改后视为通过；经委员会进一步审核后可进入答辩。 |
| > 20% | 不通过，需重大修改并进行第二次查重。 |
| 第二次仍不通过 | 不能进入后续论文评审和答辩。 |
| 有异议 | 可提交经导师批准的书面说明，由委员会审核是否可进入论文评审。 |

## Oral Defense 要求

1. 答辩由 UA office 组织，时间为 2026-06-04。
2. 学生和导师需按指定时间地点线下参加。
3. 学生需准备 PPT，阐述项目背景、目标、实验/设计方法、结果/产出分析和结论。
4. 每人约 20 分钟：10 分钟 presentation，5-10 分钟 Q&A。
5. 答辩秘书填写 Appendix VIII On-site Minutes。
6. 委员会依据评分标准填写 Appendix IX Assessment Form。

## 评分关注点

委员会评估 thesis project 时会考虑：

1. 书面论文整体质量：选题、工作量、完整性、查重水平、写作水平、创新性等。
2. 答辩 PPT 质量。
3. 答辩表现，包括项目展示和 Q&A。
4. 整个项目期间的工作表现。
5. 学术纪律与出勤。

成绩区间：

| 分数 | 等级 | 概要 |
| --- | --- | --- |
| 90-100 | excellent | 按时完成，有独到见解或创新；论文目标明确、内容完整、结果可靠、分析充分、结论有效，格式正确，答辩清晰且能准确回答问题。 |
| 80-89 | good | 按时完成；内容完整，结果和分析无错误，结论有效，格式正确，答辩基本能准确回答问题。 |
| 70-79 | fair | 按时完成；内容基本完整，无重大错误，多数结论有效，格式正确，能大致解释项目并回答多数问题。 |
| 60-69 | qualified | 按时完成；论文达到可接受水平，仅有少量小错误；答辩能说明项目大纲，但部分回答不准确。 |
| <=59 | fail | 未完成项目或态度不合格；论文质量低或有重大错误；答辩不能正确说明项目和回答问题。 |

若 senior thesis 评为 fail，ST 4001 成绩为 F，不能进入毕业流程，需下一学年重修 ST 4001。

## 学生日常过程要求

1. 每周至少与导师/共同导师定期会面 0.5 小时，汇报并讨论进展。
2. 记录每日工作活动和实验、编程、测试、分析等结果到 lab notebook。
3. 按导师指导完成研究工作和相关文档。
4. 参加所有 thesis activities；缺席需经导师和 institute 在线请假批准。
5. 未获批准缺席超过项目周期 1/3，不允许进入答辩，课程成绩会受影响。
6. 按时完成所有口头和书面报告。

## 保密项目要求

若项目受保密控制：

1. 学生、导师、评审人、答辩委员会等相关人员需签署 Appendix X ZJUI Compact on Confidential Control of Senior Thesis。
2. Thesis book 封面右上角需标注 confidential。
3. 封面需注明保密期限；保密期结束后按普通论文处理。
